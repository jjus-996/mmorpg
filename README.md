# Mmorpgik

Android MMORPG prototipi (Java, tek Activity, Canvas ile çizim). Derleme: GitHub Actions -> Releases (app-debug.apk).

Bu sürümde: açılış sinematiği, karakter oluşturma, Dünya Ağacı'nda sınıf seçimi, köy meydanı + NPC'ler,
Huzur Ormanı (uzaklaştıkça güçlenen canavarlar), 5 sınıf x 5 yetenek, ölüm/yeşil ruh ve Yaşam Pınarı.
